# Repository Instructions

Before selecting, writing, importing, or publishing any article, read and follow `NEWS_PUBLISHING_POLICY.md`.

- The policy applies to both manual work and automation.
- Do not widen the feed allowlist or change the publication limit without an explicit user request.
- Do not add a source footer to article content. Store attribution only in `source` and `source_url`.
- Do not use legacy import scripts that bypass the policy validator.
- Keep policy documentation and code enforcement in sync.
- Generated article content must never use an em dash.
