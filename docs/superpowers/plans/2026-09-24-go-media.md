- `internal/contracttest` splits `Replay` into `Execute` + `Verify`, so the upload replay can resolve the response-derived `$UPLOAD_FILENAME` binding before comparing.
- `internal/app` mounts the handler inside the existing authenticated `/api/dashboard` group and replays the three `dashboard.media.*` Node contracts.

multer/busboy details that decide behavior (`node_modules/.pnpm/multer@1.4.5-lts.2/.../lib/make-middleware.js`, `busboy@1.6.0/lib/types/multipart.js`, `lib/utils.js`):

- A request is only parsed when `type-is` says `multipart/*` **and** it has a body indicator; otherwise `req.file` is unset → 400. A non-`form-data` multipart type throws `Unsupported content type` and a missing boundary throws `Multipart: Boundary not found` (both 500).
- A part is a file when it has a truthy `filename*`/`filename` parameter or type `application/octet-stream`; the filename then goes through busboy's `basename` (everything after the last `/` or `\`, `.`/`..` → `""`). A plain `filename` is decoded as **latin1** (`defParamCharset`), `filename*` with its declared charset.
- multer skips file parts whose name is empty; otherwise it checks the field first (`LIMIT_UNEXPECTED_FILE` "Unexpected field" for any other field or a second `file`), then `fileFilter`, then streams to disk. On any error it removes the files it finished writing (a file still being written when the body is truncated stays behind).
- The part type is `type/subtype` lowercased with parameters dropped; missing or malformed → `text/plain`.

### Response shapes

- Media row: `{"id","filename","url","mime_type","size","uploaded_at"}` (`SELECT *` column order). List: `{"media":[...]}` (empty: `[]`). Upload: `201 {"media":{...}}`. Delete: `{"success":true}`. Errors: `{"error":"..."}`.

## Known Node behaviors kept (parity, deliberately not fixed)

Each is pinned by a test (named in brackets). Changing any of them needs a separately reviewed contract change, ideally after cutover.

1. **The MIME check trusts the client-declared part type; content is never sniffed.** The contract upload itself is the bytes `synthetic image bytes` declared as `image/png`. [`TestUploadRecordsTheFileLikeNode`, contract replay]
2. **changed (approved, see "Approved changes after review"): only matching image extensions are accepted.** Node kept any original extension (`evil.html` declared `image/png` was stored as `<hex>.html` and served as `text/html`). Go keeps the extension's case (`A.Photo.JPEG` → `.JPEG`) but rejects any extension that is not `.jpg`/`.jpeg`/`.png`/`.webp`/`.gif` matching the declared type. Legacy files keep their Content-Type by extension. [`TestUploadNamesAndMIMETypesMatchNode`, `TestUploadRejectionsAnswer500WithMulterMessagesAndLeaveNoFiles`, `TestStaticContentTypeFollowsTheStoredExtensionLikeNode`]
3. **Rejections are 500s, not 4xx:** invalid type, a file of 5 MiB or more, a file in another field, a second file, and malformed multipart bodies all answer 500 (Express default error handler). [`TestUploadRejectionsAnswer500WithMulterMessagesAndLeaveNoFiles`, `TestMalformedMultipartAnswers500AndLeavesNoFiles`]
4. **A file of exactly 5 MiB is rejected;** the largest accepted file is 5,242,879 bytes. [`TestUploadAcceptsFiveMiBMinusOneByte`, `TestSaveRejectsFilesThatReachFiveMiB`]
5. **UTF-8 original names are stored as latin1 mojibake** (`café.webp` → `cafÃ©.webp`), because busboy decodes plain `filename` parameters as latin1; `filename*=UTF-8''…` is decoded correctly. The stored file name only uses the extension, so the URL is unaffected. See Open question 2. [`TestUploadNamesAndMIMETypesMatchNode`]
6. **Paths in the original name are stripped** with busboy's basename (both `/` and `\`): `../../x.png` → `x.png`, `C:\dir\y.gif` → `y.gif`. An empty name after that is "no file" (400).
7. **Delete does not check references.** Articles or authors that still point at a deleted file get a dangling URL. A row whose file is already gone deletes fine (200). [`TestDeleteMatchesNodeForMissingFilesAndIDs`]
8. **Delete targets `path.basename(url)` inside the uploads directory,** whatever the row's URL says (`/uploads/../secret.txt` → `<uploads>/secret.txt`; `https://cdn.example/a/link.txt` → `<uploads>/link.txt`). [`TestDeleteNeverRemovesAnythingOutsideTheUploadsDirectory`, `TestDeleteKeepsTheRowWhenTheFileCannotBeRemoved`]
9. **Path ids are bound as strings** (SQLite integer affinity): `/media/%20402` deletes 402, `/media/abc` is 404. [`TestDeleteMatchesNodeForMissingFilesAndIDs`]
10. **The list orders by the `uploaded_at` text** with no tie-breaker; Node's seed rows use ISO (`2026-09-19T00:00:00.000Z`) while uploads use `2026-09-20 12:00:00`, and `T` sorts after a space. [`TestListOrdersByUploadedAtTextDescending`]
11. **Text fields are ignored** and a nameless file part (browsers send `filename=""` for an empty file input) is skipped. [`TestUploadIgnoresTextFieldsAndNamelessFiles`]
12. **Static serving** (plus the approved `X-Content-Type-Options: nosniff`): public (no auth), CORS `*`, `Cache-Control: public, max-age=0`, `ETag: W/"<size hex>-<mtime ms hex>"`, `Last-Modified`, `Accept-Ranges: bytes`, ranges (206), conditional 304, Content-Type by extension with send's `mime@1.6` table (no extension → `application/octet-stream`), query strings ignored, nested files and `%2F` served, dotfiles and directories 404. ## Approved changes after review (user decisions, 2026-09-24)

These deliberately diverge from Node. They were decided after the first review of this plan and are applied as follow-up commits on `go-media`.

1. **Upload filter: declared type and extension must match.** The original name's extension (Node's `path.extname`, compared case-insensitively over ASCII only, so a lookalike such as `.GİF` is rejected) must be `.jpg` or `.jpeg` for `image/jpeg`, `.png` for `image/png`, `.webp` for `image/webp`, and `.gif` for `image/gif`. Anything else, including no extension, `.png` as a whole name, `a.`, `p.png.html`, or a mismatch such as `p.png` declared `image/jpeg`, is rejected like a bad type: `500 {"error":"Only .jpg, .png, .webp, and .gif files are allowed"}` (status kept at 500 for Node parity), checked after the field check and before the size limit, leaving no file. The stored name still keeps the extension's original case. This closes the stored-XSS surface where `x.html` declared `image/png` was served as HTML from the API origin. Code: `acceptedImage` in `internal/media/http_library.go`.
2. **`X-Content-Type-Options: nosniff` on every `/uploads/*` response,** including 404s and legacy files Node accepted with other extensions. From the code review: every served file whose Content-Type is not `image/jpeg`, `image/png`, `image/webp`, or `image/gif` (legacy `.svg`, `.html`, `.htm`, `.xml`, `.txt`, `.pdf`, extension-less files, ...) also gets `Content-Security-Policy: sandbox; default-src 'none'` and `Content-Disposition: attachment`, so it is never rendered as a document on the API origin. Code: `Uploads.serve` in `internal/media/static.go`; pinned by `TestStaticSandboxesAndDownloadsLegacyNonRasterFiles`.
3. **Upload read deadline of 2 minutes.** `POST /api/dashboard/media/upload` calls `extendUploadDeadlines` (`internal/media/http_library.go`) before reading the multipart body: `http.ResponseController.SetReadDeadline(now + 2m)` (`media.UploadReadTimeout`) and `SetWriteDeadline(now + 2m30s)`. The write deadline has to move too: `net/http` arms the server's 30s `WriteTimeout` when the request headers are read, so a body that takes longer than 30s would otherwise leave no time to send the 201. Writers without deadline support (httptest recorders) are skipped. Every other route keeps the server's 15s read and 30s write timeouts. Pinned by `TestExtendUploadDeadlinesSetsTwoMinutesToRead` and `TestUploadDeadlineIsExtendedThroughTheProductionHandler` (`internal/app/upload_deadline_test.go`: an `httptest` loopback server with a 300ms `ReadTimeout` around the real `app.Handler()`, so every production middleware wrapper is in the path; the slow authenticated upload succeeds while a slow `POST /api/auth/login` on the same handler fails).
4. **Switchable storage backend, local by default.** `internal/media` defines `Storage { Save(ctx, content, originalName, contentType) (StoredFile, error); Remove(ctx, url) error }` (`library.go`); the handler and `Library` depend only on it and on `StoredFile.URL`. Backends:
   - `Uploads` (local, default): files in `UPLOADS_DIR`, URL `/uploads/<name>`, served by `GET /uploads/*`.
   - `S3Uploads` (`s3uploads.go`, `MEDIA_STORAGE=s3`): key `<MEDIA_S3_PREFIX>/<name>` (default prefix `uploads`) in `S3_FEATURE_IMAGE_BUCKET`, URL `<S3_FEATURE_IMAGE_PUBLIC_URL>/<key>`, `PutObject` with the declared content type, `public, max-age=31536000, immutable`, and a SHA-256 checksum; the body is buffered (at most 5 MiB) to checksum it; public verification reuses the feature store's check (`verifyPublic`, now parameterized by content type) and deletes the object on failure; `Remove` only accepts single-segment names directly under the media prefix. Names use the same `crypto/rand` multer pattern (`newUploadName`).
   - `NewStorage(local, s3)`: with S3 nil it is the local backend; otherwise new uploads go to S3 and `Remove` routes by URL shape (`<public URL>/<prefix>/...` → S3, anything else → `UPLOADS_DIR` with Node's basename rule), so rows from either backend keep deleting. `/uploads/*` always serves `UPLOADS_DIR` for the legacy files.
   - Config (`internal/config`): `MEDIA_STORAGE=local|s3` (default `local`, case-insensitive, anything else is an error), `MEDIA_S3_PREFIX` (default `uploads`). S3 reuses `AWS_REGION`, `S3_FEATURE_IMAGE_BUCKET`, `S3_FEATURE_IMAGE_PUBLIC_URL`; `Validate` requires them (https public URL), a non-empty prefix without `..`, and a prefix that does not overlap `S3_FEATURE_IMAGE_PREFIX`. `internal/app` opens one checked S3 client for the publisher and S3 media (`media storage check failed` when only media needs it).
   - Tests use fakes only: the in-memory object API and TLS stand-in public server from `storage_test.go` (`s3uploads_test.go`), and an in-memory bucket in `internal/app/media_s3_test.go` (upload goes to S3, the legacy file keeps serving, and both kinds of row delete through their own backend).
   - Limitation: after switching back to `local`, an S3 row's delete removes the row only; its object stays in the bucket.

Kept as Node parity by decision: the latin1-garbled original names (Known behavior 5) and 500 for rejected uploads (Known behavior 3).

## Go transport differences (inherited conventions or security hardening, documented rather than contract-visible)

The recorded fixture does not exercise any of these (the fixture defers the multer error scenarios).

| Situation | Node/Express (recorded) | Go |
|---|---|---|
| multer rejection (type, size, field) | 500 HTML error page with the error and a stack trace | 500 JSON with the same message: `Only .jpg, .png, .webp, and .gif files are allowed`, `File too large`, `Unexpected field` (the dashboard shows it instead of "Upload failed") |
| Other malformed multipart (no boundary, `multipart/mixed`, empty or truncated body, a text field of 1 MiB or more) | 500 HTML (`Multipart: Boundary not found`, `Unsupported content type`, `Unexpected end of form`, `Field value too long`) | 500 `{"error":"Internal server error"}`, cause logged |

| Whole-body size | unbounded (only the file and each text field are limited) | capped at 6 MiB (5 MiB file limit + 1 MiB for headers and discarded text fields); memory use is constant because parts stream to disk |
| Unknown or refused static path (`/uploads/missing.png`, `/uploads/`, dotfiles, `..`) | 404 HTML `Cannot GET /uploads/...` | 404 `{"error":"Not found"}` (router-wide convention) |
| `/uploads`, `/uploads/sub` (directories without a trailing slash) | 301 redirect to the trailing-slash URL, which then 404s | 404 JSON directly |
| Other methods on `/uploads/*` | 404 HTML | 405 JSON with `Allow: GET, HEAD` (router-wide convention) |
| Symlink inside the uploads directory pointing outside it | followed and served (for example `/uploads/link.txt` → a file outside) | 404: `os.Root` refuses to leave the directory. Deleting such a row removes the link, never its target (same as Node) |
| Dangling symlink named by a row | `existsSync` is false, so the link stays and the row is deleted | the link is removed too (it is inside the uploads directory), row deleted |
| Doubled slashes (`/uploads//a.png`) | normalized and served | 404 |
| Static Content-Type for extensions outside the ported table | `mime@1.6` knows ~1000 types | the table covers the image types plus `html`, `htm`, `txt`, `css`, `csv`, `md`, `js`, `json`, `xml`, `pdf`, `zip`, `mp4`, `webm`; anything else is `application/octet-stream` |
| Non-ASCII in JSON strings | literal | `encoding/json` escapes `<`, `>`, `&` (existing convention; semantically identical) |
| Unauthenticated upload with a malformed body | 401 (auth runs first) | 401 (same) |

### Task 1: `UPLOADS_DIR` configuration

Node hard-codes `apps/server/uploads` next to its database (`index.ts:12`). Go makes the directory explicit: development defaults to `<worktree>/data/uploads` (next to the dev database, git-ignored); production has **no default** and `cmd/api` refuses to start without an explicit absolute `UPLOADS_DIR`, so the new host can never silently serve an empty directory. import "strings"

// This file ports the small pieces of Node, busboy, and the `mime@1.6` table
// that decide the stored upload name, the recorded original name, and the
// Content-Type of a served upload. Each function names its Node source.

// busboyBasename ports busboy 1.6 lib/utils.js basename(): everything after
// the last '/' or '\', with "." and ".." collapsed to "".
func busboyBasename(name string) string {
	if i := strings.LastIndexAny(name, `/\`); i >= 0 {
		name = name[i+1:]
	}
	if name == "." || name == ".." {
		return ""
	}
	return name
}

// latin1ToUTF8 reproduces busboy's default parameter decoding
// (defParamCharset "latin1"): every byte of a plain filename parameter becomes
// the code point of the same value, so a UTF-8 "café.png" is recorded as
// "cafÃ©.png" exactly like Node.
func latin1ToUTF8(value string) string {
	runes := make([]rune, len(value))
	for i := 0; i < len(value); i++ {
		runes[i] = rune(value[i])
	}
	return string(runes)
}

// nodeExtname ports Node's path.posix.extname for a name without slashes:
// the text from the last '.' unless that dot starts the name
// (".png" -> "", "a." -> ".", "..png" -> ".png", ".." -> "").
func nodeExtname(name string) string {
	startDot, startPart, end := -1, 0, -1
	matchedSlash := true
	preDotState := 0
	for i := len(name) - 1; i >= 0; i-- {
		c := name[i]
		if c == '/' {
			if !matchedSlash {
				startPart = i + 1
				break
			}
			continue
		}
		if end == -1 {
			matchedSlash = false
			end = i + 1
		}
		if c == '.' {
			if startDot == -1 {
				startDot = i
			} else if preDotState != 1 {
				preDotState = 1
			}
		} else if startDot != -1 {
			preDotState = -1
		}
	}
	if startDot == -1 || end == -1 || preDotState == 0 ||
		(preDotState == 1 && startDot == end-1 && startDot == startPart+1) {
		return ""
	}
	return name[startDot:end]
}

// nodeBasename ports Node's path.posix.basename without a suffix argument:
// trailing slashes are ignored and "" or "/" yield "".
func nodeBasename(value string) string {
	value = strings.TrimRight(value, "/")
	if i := strings.LastIndexByte(value, '/'); i >= 0 {
		return value[i+1:]
	}
	return value
}

package media

import (
	"crypto/rand"
	"encoding/hex"
	"errors"
	"fmt"
	"io"
	"io/fs"
	"os"
	"strings"
)

// MaxUploadBytes is multer's limits.fileSize (apps/server/src/upload.ts). busboy
// raises the limit when a file *reaches* it, so the largest accepted upload is
// MaxUploadBytes-1 bytes and a file of exactly 5 MiB is rejected, as in Node.
const MaxUploadBytes = 5 << 20

// ErrFileTooLarge reports an upload that reached MaxUploadBytes.
var ErrFileTooLarge = errors.New("File too large")

// errUnsafeName reports a stored name that would leave the uploads directory
// or address the directory itself.
var errUnsafeName = errors.New("unsafe upload name")

// Uploads is the local uploads directory: Node's uploadRoot, served at
// /uploads/*. Every file operation goes through an os.Root opened on the
// directory, so no name (including "..", absolute paths, and symlinks that
// point elsewhere) can reach a file outside it.
type Uploads struct {
	dir    string
	random io.Reader
}

// NewUploads uses dir as the uploads directory. It does not touch the
// filesystem; the directory is opened per operation, so a missing directory
// fails requests rather than composition. cmd/api creates it at startup, like
// Node's index.ts.
func NewUploads(dir string) *Uploads {
	return &Uploads{dir: dir, random: rand.Reader}
}

// Dir returns the uploads directory.
func (u *Uploads) Dir() string { return u.dir }

// StoredFile is one saved upload.
type StoredFile struct {
	Name string // the generated file name, also the last segment of the URL
	Size int64
}

// URL is the public path Node stores in media.url.
func (f StoredFile) URL() string { return "/uploads/" + f.Name }

// Save streams content into a new file named like multer's diskStorage
// callback: 16 crypto/rand bytes as hex followed by path.extname(originalName).
// Content that reaches MaxUploadBytes is rejected with ErrFileTooLarge; on any
// error the partial file is removed.
func (u *Uploads) Save(content io.Reader, originalName string) (StoredFile, error) {
	var token [16]byte
	if _, err := io.ReadFull(u.random, token[:]); err != nil {
		return StoredFile{}, fmt.Errorf("generate upload name: %w", err)
	}
	name := hex.EncodeToString(token[:]) + nodeExtname(originalName)
	if err := checkStoredName(name); err != nil {
		return StoredFile{}, err
	}
	root, err := os.OpenRoot(u.dir)
	if err != nil {
		return StoredFile{}, fmt.Errorf("open uploads directory: %w", err)
	}
	defer root.Close()
	file, err := root.OpenFile(name, os.O_WRONLY|os.O_CREATE|os.O_EXCL, 0o644)
	if err != nil {
		return StoredFile{}, fmt.Errorf("create upload: %w", err)
	}
	size, copyErr := io.Copy(file, io.LimitReader(content, MaxUploadBytes))
	if copyErr == nil && size == MaxUploadBytes {
		copyErr = ErrFileTooLarge
	}
	closeErr := file.Close()
	if err := errors.Join(copyErr, closeErr); err != nil {
		_ = root.Remove(name)
		return StoredFile{}, err
	}
	return StoredFile{Name: name, Size: size}, nil
}

// Remove deletes the file Node's delete handler would address,
// path.join(uploadRoot, path.basename(url)). A missing file is not an error
// (Node checks existsSync first). A directory, the uploads directory itself
// (an empty, "." or ".." basename), or a path outside the directory is an
// error, as Node's unlinkSync fails for them too; nothing is removed then. A
// symlink is removed itself, never its target.
func (u *Uploads) Remove(url string) error {
	name := nodeBasename(url)
	if err := checkStoredName(name); err != nil {
		return err
	}
	root, err := os.OpenRoot(u.dir)
	if err != nil {
		return fmt.Errorf("open uploads directory: %w", err)
	}
	defer root.Close()
	info, err := root.Lstat(name)
	if errors.Is(err, fs.ErrNotExist) {
		return nil
	}
	if err != nil {
		return fmt.Errorf("stat upload: %w", err)
	}
	if info.IsDir() {
		return fmt.Errorf("remove upload %q: is a directory", name)
	}
	if err := root.Remove(name); err != nil && !errors.Is(err, fs.ErrNotExist) {
		return fmt.Errorf("remove upload: %w", err)
	}
	return nil
}

// RemoveStored deletes a file Save just created (used when recording it fails).
func (u *Uploads) RemoveStored(file StoredFile) error {
	return u.Remove(file.URL())
}

// checkStoredName accepts a single, non-empty path segment only.
func checkStoredName(name string) error {
	if name == "" || name == "." || name == ".." || strings.ContainsAny(name, "/\x00") {
		return fmt.Errorf("%w: %q", errUnsafeName, name)
	}
	return nil
}

// MountStatic registers GET and HEAD /uploads/* on the root router, the Go
// counterpart of app.use("/uploads", express.static(uploadRoot)) (app.ts:30).
func (u *Uploads) MountStatic(router chi.Router) {
	router.Get("/uploads/*", u.serve)
	router.Head("/uploads/*", u.serve)
}

// serve reproduces serve-static 1.16 / send 0.19 defaults for files: the same
// Content-Type table, "Cache-Control: public, max-age=0", a weak ETag of
// W/"<size hex>-<mtime ms hex>", Last-Modified, byte ranges, and conditional
// 304s. Missing files, directories, dotfiles (any segment starting with "."),
// and anything outside the uploads directory answer 404.
func (u *Uploads) serve(w http.ResponseWriter, r *http.Request) {
	name, ok := staticName(r.URL.Path)
	if !ok {
		notFound(w)
		return
	}
	root, err := os.OpenRoot(u.dir)
	if err != nil {
		notFound(w)
		return
	}
	defer root.Close()
	file, err := root.Open(name)
	if err != nil {
		notFound(w)
		return
	}
	defer file.Close()
	info, err := file.Stat()
	if err != nil || !info.Mode().IsRegular() {
		notFound(w)
		return
	}
	header := w.Header()
	header.Set("Cache-Control", "public, max-age=0")
	header.Set("ETag", fmt.Sprintf(`W/"%x-%x"`, info.Size(), info.ModTime().UnixMilli()))
	header.Set("Content-Type", staticContentType(name))
	http.ServeContent(w, r, "", info.ModTime(), file)
}

// staticName maps the decoded request path to a slash-separated name inside
// the uploads directory, rejecting empty segments (directories), segments that
// start with "." (send's dotfiles: "ignore", which also covers "." and ".."),
// and NUL bytes.
func staticName(requestPath string) (string, bool) {
	name, ok := strings.CutPrefix(requestPath, "/uploads/")
	if !ok || name == "" || strings.ContainsRune(name, 0) {
		return "", false
	}
	for _, segment := range strings.Split(name, "/") {
		if segment == "" || strings.HasPrefix(segment, ".") {
			return "", false
		}
	}
	return name, true
}

func notFound(w http.ResponseWriter) {
	writeJSON(w, http.StatusNotFound, map[string]string{"error": "Not found"})
}

func writeJSON(w http.ResponseWriter, status int, value any) {
	body, err := json.Marshal(value)
	if err != nil {
		body = []byte(`{"error":"Internal server error"}`)
		status = http.StatusInternalServerError
	}
	w.Header().Set("Content-Type", "application/json; charset=utf-8")
	w.WriteHeader(status)
	_, _ = w.Write(body)
}

// formatSqliteTimestamp (UTC "YYYY-MM-DD HH:MM:SS"). If the row cannot be
// written the file is removed, so a failed upload leaves no orphan (Node
// leaves the file behind).
func (l *Library) Record(ctx context.Context, file StoredFile, originalName, mimeType string) (Item, error) {
	item, err := l.store.Insert(ctx, NewItem{

		URL:        file.URL(),

		Size:       file.Size,
		UploadedAt: l.now().UTC().Format(time.DateTime),

		}
		return Item{}, err
	}
	return item, nil
}

	if err != nil {
		return err
	}
	if err := l.files.Remove(item.URL); err != nil {
		return err
	}
	return l.store.Delete(ctx, id)

// 1 MiB for part headers and any text fields, which are discarded. Node has no
// total cap; this bounds work, while memory stays constant because parts are
// streamed straight to disk.

// allowedMIMETypes is upload.ts's fileFilter allowlist, compared with the
// part's lowercased type/subtype (busboy drops parameters).
var allowedMIMETypes = map[string]bool{

	messageUnexpectedField = "Unexpected field"

// uploadError is a multer rejection. Node answers each with Express's default
// 500 HTML page; Go answers 500 with the same message as JSON.
type uploadError struct{ message string }

func (e *uploadError) Error() string { return e.message }

var errNoFile = errors.New("No file uploaded")

type libraryService interface {

	Record(context.Context, StoredFile, string, string) (Item, error)

// Handler serves the authenticated dashboard media routes.
type Handler struct {
	library libraryService
	files   fileSaver
	logger  *slog.Logger
}

func NewHandler(library libraryService, files fileSaver, logger *slog.Logger) *Handler {
	return &Handler{library: library, files: files, logger: logger}
}

// Mount registers the routes relative to /api/dashboard. The caller owns
// authentication: every route here must sit behind RequireAuth.

	router.Post("/media/upload", h.upload)

func (h *Handler) list(w http.ResponseWriter, r *http.Request) {

	if err != nil {
		h.internalError(w, r, "list media", err)
		return

func (h *Handler) upload(w http.ResponseWriter, r *http.Request) {

	var rejected *uploadError
	switch {
	case errors.Is(err, errNoFile):
		writeJSON(w, http.StatusBadRequest, map[string]string{"error": errNoFile.Error()})
		return
	case errors.As(err, &rejected):
		writeJSON(w, http.StatusInternalServerError, map[string]string{"error": rejected.message})
		return
	case err != nil:

		return

		return

type receivedUpload struct {
	file         StoredFile
	originalName string
	mimeType     string
}

// receive ports multer 1.4.5-lts.2 upload.single("file") over busboy 1.6:
//   - a request that is not multipart has no file (an empty multipart body is
//     malformed, a 500, as busboy reports "Unexpected end of form");
//   - a file part is one with a filename parameter (or an
//     application/octet-stream part); an empty name after busboy's basename is
//     skipped, as multer ignores files without a name;
//   - a file in any field but "file", or a second one there, is "Unexpected
//     field"; then the MIME allowlist applies; then the size limit;
//   - text fields are ignored.
//
// Parts are streamed; only the accepted file touches the disk, and it is
// removed again if a later part fails.
func (h *Handler) receive(w http.ResponseWriter, r *http.Request) (receivedUpload, error) {
	mediaType, params, err := mime.ParseMediaType(r.Header.Get("Content-Type"))
	if err != nil || !strings.HasPrefix(mediaType, "multipart/") {
		return receivedUpload{}, errNoFile
	}
	if mediaType != "multipart/form-data" {
		return receivedUpload{}, errors.New("unsupported multipart content type " + mediaType)
	}
	if params["boundary"] == "" {
		return receivedUpload{}, errors.New("multipart: boundary not found")
	}
	reader := multipart.NewReader(http.MaxBytesReader(w, r.Body, maxUploadRequestBytes), params["boundary"])
	var accepted *receivedUpload
	fail := func(err error) (receivedUpload, error) {
		if accepted != nil {
			if removeErr := h.files.RemoveStored(accepted.file); removeErr != nil {
				err = errors.Join(err, removeErr)
			}
		}
		return receivedUpload{}, err
	}
	for {
		part, err := reader.NextRawPart()
		// Only a bare io.EOF is the closing boundary; the reader wraps io.EOF
		// ("multipart: NextPart: EOF") for bodies that end without one.
		if err == io.EOF {
			break
		}
		if err != nil {
			return fail(err)
		}
		field, filename, isFile := describePart(part)
		if !isFile || filename == "" {
			if _, err := io.Copy(io.Discard, part); err != nil {
				return fail(err)
			}
			continue
		}
		if field != uploadField || accepted != nil {
			return fail(&uploadError{messageUnexpectedField})
		}
		partType := partMIMEType(part.Header.Get("Content-Type"))
		if !allowedMIMETypes[partType] {
			return fail(&uploadError{messageInvalidType})
		}
		file, err := h.files.Save(part, filename)
		if errors.Is(err, ErrFileTooLarge) {
			return fail(&uploadError{ErrFileTooLarge.Error()})
		}
		if err != nil {
			return fail(err)
		}
		accepted = &receivedUpload{file: file, originalName: filename, mimeType: partType}
	}
	if accepted == nil {
		return receivedUpload{}, errNoFile
	}
	return *accepted, nil
}

// describePart reads a part's Content-Disposition like busboy: parts that are
// not form-data are skipped; filename* wins over filename; a plain filename is
// decoded as latin1; busboy's basename is applied.
func describePart(part *multipart.Part) (field, filename string, isFile bool) {
	disposition := part.Header.Get("Content-Disposition")
	kind, params, err := mime.ParseMediaType(disposition)
	if err != nil || kind != "form-data" {
		return "", "", false
	}
	name, hasName := params["filename"]
	if hasName && !strings.Contains(strings.ToLower(disposition), "filename*") {
		name = latin1ToUTF8(name)
	}
	isFile = (hasName && name != "") || partMIMEType(part.Header.Get("Content-Type")) == "application/octet-stream"
	return params["name"], busboyBasename(name), isFile
}

// partMIMEType ports busboy's part Content-Type handling: the lowercased
// type/subtype without parameters, or text/plain when absent or malformed.
func partMIMEType(value string) string {
	if value == "" {
		return "text/plain"
	}
	mediaType, _, err := mime.ParseMediaType(value)
	if err != nil || !strings.Contains(mediaType, "/") {
		return "text/plain"
	}
	return mediaType
}
